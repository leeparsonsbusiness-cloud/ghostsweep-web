# GhostSweep Icons

To complete the extension setup, you need to add icon files:

## Required Icons:
- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## Design Suggestions:
- Use a ghost emoji (👻) or ghost silhouette
- Colors: Purple/blue gradient background with white ghost
- Simple, clean design that's recognizable at small sizes

## Temporary Solution:
The extension will work without icons, Chrome will use a default icon placeholder.

You can find free icons at:
- https://www.flaticon.com (search "ghost")
- https://iconify.design (search "ghost")
- Or create custom icons using any design tool

Make sure icons are in PNG format and exact sizes specified above.
